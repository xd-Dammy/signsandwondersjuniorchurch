# RCCG Signs and Wonders Juniors Church Gallery
A lightweight, fast, and completely free decoupled photo gallery platform built for the **Junior Media Team**. Hosted for free via GitHub and Netlify.

## Features
- **Decap CMS Admin Panel:** Add events and drop photos straight from an iPhone 13 or personal mobile device.
- **Responsive Grid:** Optimized for parents and coordinators to view highlights on any smartphone screen.
- **Fail-Safe Architecture:** Frontend code is separate from data records (`content/events.json`).
